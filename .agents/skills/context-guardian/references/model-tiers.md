# 🎚️ مصفوفة طبقات الموديلات (Model Tiers)

## الموديل الضعيف (صغير/رخيص/سياق ضيق)

- دفعة = ملف واحد + تحقق واحد. لا دفعات متوازية.
- أوامر قصيرة حرفية، واطلب إظهار الدليل بعد كل خطوة.
- أعد إرسال حزمة السياق عند أي انحراف (رخيصة: <8k حرف).

## الموديل القوي (كبير/سياق واسع)

- دفعات متوازية مسموحة (ملفات مستقلة معاً).
- تفويض via `delegate_task` للأعمال المتوازية + تحقق ذاتي من الملفات.
- الحارس يراجع النتائج لا الخطوات.

## المشترك (غير قابل للتفاوض)

- حزمة السياق المصغرة للجميع — القوي أيضاً يضيع في السياق الملوث.
- لا مهمة منتهية بلا COMPLETED + ROADMAP محدثين.
