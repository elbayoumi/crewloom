# 📋 نموذج طلب البيانات (Data Request Protocol)

## القاعدة: الموظف الذي يتوقف لنقص بيانات يسأل فوراً — لا يخمّن ولا يتجمد

أي موظف (أو وكيل) واجه مهمة تنقصها مدخلات، يخرج بهذا النموذج حرفياً:

```markdown
## 🛑 أحتاج بيانات للإكمال — [اسم المهمة]

**الناقص (بالضبط):**
1. [البيان 1: مثال: مفتاح API لـ X — أين تجده: لوحة تحكم X ← Settings]
2. [البيان 2: مثال: قرار: الميزانية 30 أم 60؟]

**لماذا يمنع التقدم:** [جملة واحدة: بلا المفتاح لا يمكن تشغيل N عقدة n8n]

**البديل المؤقت (إن وجد):** [أكمل بـ mock/بيانات تجريبية حتى تصل الحقيقية — أو: لا يوجد]

**أثر التأخير:** [يؤخر التسليم من X إلى Y إن لم يصل خلال Z]
```

## قواعد الطلب

1. **محدد لا عام:** "أحتاج بيانات" مرفوضة — اذكر الاسم والمكان والسبب.
2. **بديل دائماً:** اقترح ما يمكن إنجازه بدونها حتى لا يتوقف كل شيء.
3. **دفعة واحدة:** اجمع كل النواقص في طلب واحد — ممنوع التنقيط كل ساعة.
4. **للمالك:** الرد بكلمة أو لصق القيمة — لا شرح مطلوب منك.
