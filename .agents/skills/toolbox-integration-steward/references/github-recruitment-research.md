# بحث GitHub لتخصص تشغيل السكربتات من بوابة داخلية

تاريخ الفحص: 2026-09-28 UTC. الاستعلامات: `script UI input schema job audit GitHub` و`developer catalog metadata git Backstage` و`Rundeck job options execution`. النطاق: أفكار عقد الميتاداتا ونموذج المدخلات وسجل التنفيذ؛ لا نسخ كود أو تركيب منصة خارجية.

| المستودع والمصدر | ملاءمة المهمة | دليل الانتشار وقت الفحص | الصيانة والجودة | الإبداع العملي | الترخيص والمتطلبات | القرار |
|---|---|---|---|---|---|---|
| [Windmill](https://github.com/windmill-labs/windmill) | يحوّل مدخلات السكربت إلى UI وتنفيذ مسجل | 18.1k نجمة، 1.1k fork على GitHub؛ المستخدمون الفعليون غير متحققين | مستودع نشط وتوثيق تشغيل؛ تجربة محلية كاملة تتطلب Rust/Postgres ورنتايمات متعددة | توليد نماذج من مدخلات السكربت؛ نستلهم شكل العقد فقط | AGPL/Apache بحسب الملفات؛ لا يُنسخ كود | مرجع لنموذج المدخلات؛ لا تركيب بسبب حجم المنصة |
| [Backstage](https://github.com/backstage/backstage) و[دليل الكتالوج](https://github.com/backstage/backstage/blob/master/docs/features/software-catalog/index.md) | مصدر ميتاداتا في Git مع بوابة اكتشاف | 34.5k نجمة، 7.7k fork؛ الاستخدام الفعلي لا يستنتج من النجوم | مشروع مفتوح نشط، اختبار/توثيق واسع في المستودع | الميتاداتا بجوار الكود، والكتالوج يعرض المالك والروابط | Apache-2.0؛ بناء بوابة كاملة أكبر من حاجة الوكالة | مرجع لعقد JSON بجوار السكربت |
| [Rundeck](https://github.com/rundeck/rundeck) | خيارات تنفيذ، صلاحيات، وسجل jobs | 6.3k نجمة، 987 fork؛ التبني الفعلي غير متحقق | مشروع مفتوح مع web/API/CLI ووثائق؛ التشغيل يحتاج بيئة أكبر | فصل job definition عن التشغيل وسجل النتائج | Apache-2.0؛ لا تركيب | مرجع لسجل التشغيل وتصنيف الأدوات عالية الأثر |

التجربة المحدودة للأنماط: تطبيق مبدأ ميتاداتا Git ونموذج مدخلات UI محلياً على `validate_script_pacing.py`؛ `vault.py validate` أعاد PASS، ورابط `/skills` إلى `/?q=video-script-architect` أظهر أداة واحدة قابلة للتشغيل ونص مدخلاتها. هذا يثبت نمط التكامل المحلي فقط، ولا يختبر Windmill أو Backstage أو Rundeck نفسها.
