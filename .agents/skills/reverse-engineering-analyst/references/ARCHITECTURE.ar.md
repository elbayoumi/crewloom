# مرجع البنية التخصصية

مرجع للدور؛ النطاق العام ودعم الأدوات محددان في الدليل الإنجليزي وفهرس الأدوات.

```
[Reverse Engineering Analyst]
        │
        ├─► [Authorization gate]   تفويض مكتوب + هدف محدد + SHA-256
        │
        ├─► [Analysis tool]        REA (MCP أو CLI) أو أداة معتمدة أخرى
        │      ├─ ساكن: صيغة، بيانات وصفية، تفكيك، مراجع
        │      └─ تشغيلي: عملية، مصحح، حقن  ← يحتاج تفويضاً منفصلاً
        │
        ├─► [Findings packet]      claims + evidence + limitations
        │
        └─► [re-findings checker]  يتحقق من البصمة والتفويض وروابط الأدلة
```

REA يعمل محلياً ولا يوفر sandbox؛ استخدم VM أو حاوية للعينات العدائية.
