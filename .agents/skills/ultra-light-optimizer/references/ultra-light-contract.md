# 📜 عقد الخفة القصوى (Ultra-Light Contract v1.0)
## ملزم لأي وكيل يكتب أو يعدّل كوداً في الوكالة — 2026-09-26

> **القاعدة:** أي كود جديد أو معدَّل لا يُعتبر منجزاً حتى يحقق هذا العقد أو يوثّق استثناءً بسبب حقيقي.
> المصادر: OWASP Nest حادثة N+1 (151 كويري بدل 1)، DataLoader (21→3 calls)، GitTrek (15s→3s single-fetch)، contributor.info (TTI 5s→3.5s).

---

## 1️⃣ قاعدة البيانات (DB) — سقف: endpoint列表 ≤2 كويري مهما كان N

| # | البند | الفحص الآلي |
|---|---|---|
| DB-1 | ممنوع `SELECT *` — أعمدة صريحة فقط | `R-HARD-01` |
| DB-2 | ممنوع كويري داخل loop — batch/join/DataLoader/`select_related` بدلها | `R-HARD-02` |
| DB-3 | أي list لازم pagination (`LIMIT ≤50`، افتراضي 20) + `COUNT` منفصل كحد أقصى | `R-HARD-03` |
| DB-4 | أي عمود يُفلتر/يُرتَّب عليه لازم index (أو سبب موثق لتعذّره) | مراجعة يدوية + `EXPLAIN` |

## 2️⃣ الـ API والريكويستات — سقف: list ≤100KB، detail ≤50KB

| # | البند | الفحص الآلي |
|---|---|---|
| API-1 | field selection — لا ترجع حقولاً لا يطلبها العميل | مراجعة |
| API-2 | بيانات متداخلة (nested) تُجلب batch لا N ريكويست (نمط GitHub GraphQL 400→9) | `R-HARD-04` (fetch في loop) |
| API-3 | بيانات شبه ثابتة عليها `Cache-Control` أو ETag (لا polling أعمى) | مراجعة |
| API-4 | بحث حي عليه debounce ≥300ms + إلغاء الطلب السابق | مراجعة |

## 3️⃣ الحزمة والعرض (Bundle) — سقف: لا مكتبة ثقيلة بلا مبرر

| # | البند | الفحص الآلي |
|---|---|---|
| B-1 | ممنوع `lodash` الكاملة/`moment` — بدائل (`date-fns`، import جزئي) | `R-HARD-05` |
| B-2 | أي مكتبة >50KB تُحمَّل dynamic import فقط | مراجعة |
| B-3 | صور `WebP/AVIF` + `lazy` خارج首屏 | مراجعة |
| B-4 | ممنوع `console.log` في كود الإنتاج | `R-SOFT-01` |

## 4️⃣ الـ Realtime — سقف: حدث واحد مجمّع بدل N أحداث

| # | البند |
|---|---|
| RT-1 | بايلود السوكت أدنى حقول لازمة فقط |
| RT-2 | presence/list تُبث دفعة واحدة، لا emit داخل loop لكل عنصر |
| RT-3 | throttle مؤشرات الكتابة (typing) — حدث/2s لكل مستخدم كحد أقصى |

## الاستثناء الموثق (بدل الكذب أو الحجب)

أي بند غير قابل للتطبيق يُوثَّق سطراً واحداً: `البند — السبب — المسؤول`. الاستثناء يُراجَع كل إصدار، لا يُورَّث بصمت.
