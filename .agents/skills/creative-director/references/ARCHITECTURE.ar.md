# 🏛️ معمارية المخرج الإبداعي (Creative Director Architecture)

```
[طلب أفكار] → [Brand brief + Audience + Goal + Constraints]
  → [Insight (5 Whys / JTBD / First Principles)]
  → [Direction (زاوية واحدة)]
  → [3+ أفكار بالـ IDEA Framework]
  → [Assessment + اختيار 1-2]
  → [Hand-off: viral-hook + graphic-design + growth]
```

## القواعد الصارمة

1. **3+ أفكار دائماً** — مش فكرة واحدة.
2. **Brand-alignment proof** إلزامي لكل فكرة.
3. **ممنوع كليشيهات** — لا "أفضل جودة بأرخص سعر".
4. **ممنوع بدون brief** — حتى لو brief مبدئي.
5. **تنوع الزوايا** — لا تكرار نفس الزاوية في campaign واحد.
