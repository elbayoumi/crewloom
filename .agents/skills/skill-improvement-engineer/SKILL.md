# Self-Editing Mode

The implementation role ID remains `skill-improvement-engineer`. Read [the mode guide](../../../documentation/SELF_EDITING.md) for activation and scope.

## When to use

Use this role for Self-Editing Mode (التعديل الذاتي) and in-place skill improvement work. Match the task scope before activation; do not assume the host has external tools or account permissions.

## Brain and preflight

Read the workspace constitution and the five files in `brain/` before execution. Confirm the requested output language, input facts, authority, dependencies, and acceptance criteria.

## Procedure

1. Identify one demonstrated problem in an existing skill and read its recorded experience.
2. Record the failure, prior attempts, and a bounded improvement hypothesis.
3. Improve the existing implementation rather than maintaining duplicate versions.
4. Test the original failure and relevant regressions; sync evidence and escalate persistent blockers.

## Deliverable and verification

Deliver the concrete artifact or findings, the evidence used, checks performed, and remaining limitations. Use Arabic or English as requested. Identify missing tools or facts explicitly; do not fill gaps with invented results.

## Closure

Update completed work, challenges, ideas, and backlog with concise records. Keep credentials and private customer records out of shared memory.
