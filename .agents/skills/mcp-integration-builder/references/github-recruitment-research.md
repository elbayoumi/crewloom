## التجربة
`scripts/validate_mcp_config.py` (منطق البوابة الخاص، مكتبة قياسية): 5 حالات فعلية —
config سليم (filesystem stdio) → PASS exit 0؛
بلا `command` → FAIL exit 2؛
env بقيمة `sk-live-...` → FAIL exit 2 (سر مضمّن)؛
transport مجهول → FAIL exit 2؛
ملف بلا `mcpServers` → FAIL exit 2. تشغيل سيرفر رسمي حي (filesystem/fetch) غير متحقق هنا — أول تركيب حي موثّق كـ P1 في ROADMAP_TODO.
