# Bring your own project context

Crewloom includes general procedures and selected local tools. Detailed playbooks also name project inputs that are deliberately outside this distribution: contracts, pricing, delivery plans, identity tokens, production targets, access grants, and account credentials.

A named external policy is a requirement to supply a real project document, not a file that Crewloom pretends to contain. The public constitution overrides agency-specific schedules, staffing references, and commercial assumptions in inherited references.

| Input | Required evidence |
| --- | --- |
| Commercial terms | Owner-approved scope, pricing, currency and timeline |
| Identity | Approved project tokens, typography, voice and asset rights |
| Deployment | Authorized target, environment, secrets by reference and rollback |
| Tests | Current acceptance criteria and representative inputs |
| External accounts | Host tools and explicit action authorization |

Do not execute an inherited command unless its script exists in the public tool catalog and its actual inputs have been inspected. Treat source-specific historical maturity and performance claims as upstream context, not validation of this release. Some tool output remains Arabic; the shared agent policy supports both response languages.
